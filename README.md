# Tic-tac-toe-c
Tic-tac-toe game written in C using raylib. 


## Requirements

- GCC
- Make
- raylib

### Install raylib

#### Arch Linux

```bash
sudo pacman -S raylib
```
---
#### Debian 

```bash
sudo apt install libraylib-dev
```
---
#### macOS 

```bash
brew install raylib
```
---
### Clone the repository

```bash
git clone https://github.com/based-watermelon/tic-tac-toe-c.git
```

### Build and Run 

```bash
make
./game
```
### Clean 

```bash
make clean
```
